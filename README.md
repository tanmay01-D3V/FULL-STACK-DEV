# Full Stack Dev

Welcome to my **full-stack development workspace**. This repository documents the projects, experiments, assignments, and practical work I have built while learning how modern web applications are designed from the browser to the database.

It has grown from <u>HTML5</u> and <u>CSS3</u> exercises into a broad collection of **frontend applications, REST APIs, real-time systems, database work, and AI-focused MongoDB labs**.

## What I Have Worked With

### Frontend

- <u>HTML5</u>, semantic markup, forms, browser APIs, and accessibility fundamentals
- <u>CSS3</u>, responsive layouts, <u>Flexbox</u>, <u>CSS Grid</u>, animations, and interactive UI
- <u>JavaScript</u>, DOM manipulation, asynchronous programming, promises, and object-oriented programming
- <u>React</u>, component-based UI, hooks, state management, and practical application patterns
- <u>Redux</u>, <u>Vite</u>, and <u>Next.js</u>

### Backend and APIs

- <u>Node.js</u> and <u>Express.js</u>
- **REST API design**, routing, middleware, controllers, and CRUD workflows
- <u>NestJS</u> modules, controllers, services, configuration, authentication, and testing foundations
- <u>JWT</u> authentication, password hashing with <u>bcrypt</u>, <u>CORS</u>, validation, and error handling
- <u>Firebase</u> and <u>Firebase Admin</u> integrations

### Data and Cloud

- <u>MongoDB</u>, <u>Mongoose</u>, and database-backed application design
- <u>MongoDB Atlas</u> concepts, aggregation, vector search, retrieval-augmented generation, and AI agents
- <u>Firebase</u> data and backend services

### Real-Time and Application Architecture

- <u>Socket.IO</u> and event-driven communication
- Chat applications, live stopwatch experiences, multiplayer-style interactions, and socket-based CRUD
- **Full-stack separation** between frontend clients and backend services

## Running a Project

Most <u>JavaScript</u> projects are self-contained and include their own `package.json`. Open the project directory, install its dependencies, and use the scripts defined there:

```bash
npm install
npm run dev
```

**Important:** Some projects use a different start script or contain separate `Frontend` and `Backend` directories, so check the local `package.json` before running them. The <u>MongoDB</u> notebooks include their own [`requirements.txt`](Backend/MongoDB/genai-devday-notebooks/requirements.txt).
